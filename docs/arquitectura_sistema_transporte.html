Motor Geoespacial PostGIS 3.4
PostgreSQL 15 Alpine (Contenedor odoo_transporte_db)

PostGIS no solo almacena datos tabulares, sino que actúa como un motor geométrico en tiempo real para calcular distancias, desvíos y correspondencia de trazas:

  • ST_LineLocatePoint(shape, pt): Proyecta la posición exacta del bus sobre la traza oficial de la ruta en metros y porcentaje recorrido (0% a 100%).
  • ST_Distance(shape::geography, pt::geography): Mide el desvío físico en metros respecto al itinerario autorizado por el GVMT.
  • ST_DWithin(geom, stop_geom, radius): Detección automática de arribos y salidas de paradas sin bucles en Python.
  • ST_Buffer(geom, radius): Generación de geocercas circulares alrededor de cabeceras, terminales y puntos de control.
PostGIS 3.4.2 SRID 4326 (WGS84) GiST Indexes Geography Types
⚡
Redis 7 para Telemetría Viva
Contenedor odoo_transporte_redis (Puerto 6379)

Para evitar bloquear la base de datos relacional con cientos de escrituras por segundo, Redis asume el rol de Estado de Flota en Vivo:

  • fleet:live:{vehicle_id}: Hash con lat, lon, velocidad, rumbo, ignición, retraso y estado operativo en tiempo real.
  • auth:session:{session_id}: Caché de sesiones Odoo (TTL 300s) que permite al microservicio FastAPI verificar usuarios y roles sin consultar la DB en cada request.
  • headway:cache: Almacena las alertas activas de pegonamiento para respuesta instantánea en el tablero lineal.
Redis 7 Alpine In-Memory TTL Pub/Sub Engine JSON Serialization

Odoo 18.0 Community ERP
Núcleo Empresarial y Motor Transaccional

Odoo 18 está desarrollado íntegramente en Python y opera sobre un servidor HTTP multi-threaded basado en Werkzeug:

  • ORM (Object-Relational Mapping): Abstracción completa de SQL con validaciones de tipos, métodos computados reactivos (@api.depends), constraints de integridad y tracking en chatter.
  • Seguridad Multi-Tenant: Reglas de registro (ir.rule) que inyectan cláusulas WHERE automáticas en cada consulta SQL para que un operador jamás acceda a los datos de otra empresa.
  • Crons Automáticos: Tareas programadas en background que recalculan el CBD/IFO cada 5 minutos y evalúan el cumplimiento operativo diario.
  • Facturación SIFEN / DNIT: Emisión de boletos electrónicos homologados con firma digital, CDC de 44 dígitos y generación de código QR.
Python 3.10/3.11 Odoo 18.0 ORM Werkzeug WSGI Jinja2 / QWeb psycopg2-binary

Proxy Inverso Dinámico Interno
Controlador api_gps.py en Odoo

Para evitar abrir puertos como el 8088 hacia internet o alterar la configuración del firewall:

  • El controlador de Odoo intercepta peticiones a /headway, /map, /compliance y /api/v1/....
  • Reenvía internamente la petición vía HTTP al microservicio FastAPI (http://gps_broker:8088) a través de la red privada de Docker.
  • Transfiere transparentemente las cookies de sesión (session_id) garantizando Single Sign-On (SSO) y respetando los permisos del usuario activo.
  • Sirve la respuesta directamente bajo HTTPS en el puerto 443 a través del mismo dominio dashboardtransito.agsrl.com.py.

FastAPI & Ingesta Asíncrona
Contenedor odoo_transporte_gps_broker

Construido sobre FastAPI y Uvicorn, diseñado para concurrencia masiva sin esperas bloqueantes:

  • WebSockets en Vivo (/ws/live): Mantiene conexiones abiertas con los radares web enviando cambios de posición con 0ms de retardo, con fallback automático a HTTP polling cada 15 segundos si se interrumpe la conexión.
  • Consumidor MQTT (mqtt_consumer.py): Hilo de ejecución persistente conectado a Mosquitto para recibir telemetría binaria de buses en ruta.
  • Autenticación Unificada (auth.py): Consulta /web/session/get_session_info en Odoo para validar roles multi-tenant y aplicar filtros por empresa automáticamente.
FastAPI 0.109+ Uvicorn (ASGI) WebSockets Asyncio / Pydantic v2 Paho-MQTT

Motores de Inteligencia Operativa
Algoritmos Matemáticos & Telemetría Predictiva

Módulos especializados que transforman coordenadas brutas en información de toma de decisiones:

  • Detector de Pegonamiento (headway_service.py): Mide la distancia física y el tiempo entre coches consecutivos en el mismo ramal. Si la brecha cae por debajo de 800m, emite alertas sonoras y visuales para evitar la canibalización de pasajeros.
  • ETA Predictivo por Parada (eta_service.py): Calcula el tiempo estimado de llegada de los próximos buses a cada parada física, con código QR escaneable por pasajeros.
  • Capa Waze CCP: Integración en tiempo real de alertas de congestión, accidentes y obras de Waze for Cities sobre el mapa de la flota.
Headway Engine Bunching Alerts Predictive ETA Waze CCP Integration

Odoo Web Client: OWL Framework
Odoo Web Library (Arquitectura Reactiva Moderna)

Odoo 18 utiliza OWL, un framework JavaScript moderno desarrollado por Odoo con conceptos similares a React y Vue:

  • Componentes Reactivos: Vistas interactivas con estado interno reactivo (useState), Virtual DOM y hooks de ciclo de vida (onWillStart, useEffect).
  • Mesa de Asignación de Turnos (transit_roster_board.js): Tablero interactivo para arrastrar choferes a turnos (T1/T2), resolver solapamientos, balancear horas semanales y exportar cuadrantes.
  • Plantillas QWeb (XML): Declaración de interfaces enriquecidas compiladas en el navegador con soporte de directivas t-if, t-foreach, t-on-click.
