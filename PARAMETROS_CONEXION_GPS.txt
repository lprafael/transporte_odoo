2. OPCIÓN A: TRANSMISIÓN VÍA API REST (HTTP POST) - RECOMENDADA
--------------------------------------------------------------------------------
- Endpoint URL:
    http://187.77.247.23:8088/api/v1/telemetry
    (Alias admitido: http://187.77.247.23:8088/telemetry/gps)

- Método HTTP:
    POST

- Encabezados (Headers) Obligatorios:
    Content-Type: application/json
    X-Device-Token: GPS_DEVICE_SECRET_2026

- Formato del Payload (JSON UTF-8):
{
  "mean_id": "00016",
  "license_plate": "AARX 104",
  "agency_id": "004B",
  "route_id": "020c",
  "driver_id": "4589123",
  "latitude": -25.33412,
  "longitude": -57.52145,
  "velocidad": 38.5,
  "rumbo": 295.0,
  "odometer_km": 48230.5,
  "precision": 8,
  "fecha_hora": "2026-10-15T15:30:00Z",
  "type": 2
}

- Descripción de Campos del JSON:
  * mean_id:       (Texto, Obligatorio) N° de Interno o Identificador del móvil (ej: "00016", "100", "IOT100").
  * license_plate: (Texto, Opcional) Matrícula / Chapa Mercosur (ej: "AARX 104", "IOT100").
  * agency_id:     (Texto, Obligatorio) Debe ser exactamente "004B".
  * route_id:      (Texto, Obligatorio) Código de ramal oficial en servicio (ej: "020c", "020d", "020e", "020f").
  * driver_id:     (Texto, Opcional) N° de Cédula o Legajo del chofer.
  * latitude:      (Decimal WGS84, Obligatorio) Latitud geográfica (ej: -25.334120). No enviar 0.0.
  * longitude:     (Decimal WGS84, Obligatorio) Longitud geográfica (ej: -57.521450). No enviar 0.0.
  * velocidad:     (Decimal, Obligatorio) Velocidad instantánea en km/h (ej: 38.5).
  * rumbo:         (Decimal, Obligatorio) Orientación en grados de 0 a 360 (ej: 295.0).
  * odometer_km:   (Decimal, Opcional) Kilometraje acumulado del odómetro (ej: 48230.5).
  * precision:     (Entero, Opcional) Margen de precisión satelital en metros (HDOP).
  * fecha_hora:    (Texto ISO-8601 UTC, Obligatorio) Marca de tiempo satelital (ej: "2026-10-15T15:30:00Z").
  * type:          (Entero, Obligatorio) Estado operativo del viaje:
                     0 = INICIADO (Salida de cabecera)
                     2 = OPERANDO (En recorrido / habitual)
                     1 = FINALIZADO (Llegada a destino)

- Ejemplo cURL de Prueba Rápida:
curl -X POST "http://187.77.247.23:8088/api/v1/telemetry" \
  -H "Content-Type: application/json" \
  -H "X-Device-Token: GPS_DEVICE_SECRET_2026" \
  -d '{
    "mean_id": "00016",
    "license_plate": "AARX 104",
    "agency_id": "004B",
    "route_id": "020c",
    "latitude": -25.33412,
    "longitude": -57.52145,
    "velocidad": 38.5,
    "rumbo": 295.0,
    "odometer_km": 48230.5,
    "fecha_hora": "2026-10-15T15:30:00Z",
    "type": 2
  }'

- Respuesta Exitosa del Servidor (HTTP 200 OK):
