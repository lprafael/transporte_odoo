transit_concessionaire MULTI-TENANT ROOT
PK: id | FKs: partner_id
Entidad matriz del modelo Multi-Tenant. Representa a las empresas de transporte público autorizadas (ej. Consorcio Arapotí, Transportes San Lorenzo). Todos los vehículos, líneas, despachos y usuarios quedan aislados por esta clave.
Columna Tipo de Dato Restricciones Descripción Funcional
id INTEGER PRIMARY KEY Identificador numérico autoincremental de la concesionaria.
name VARCHAR(255) NOT NULL Razón social o denominación comercial (ej: Consorcio Arapotí Línea 20).
code VARCHAR(64) UNIQUE Código de operador asignado por el VMT (ej: 004B, CONC-L20).
vat_ruc VARCHAR(32) OPTIONAL Registro Único de Contribuyentes para liquidación y clearing SIFEN.
partner_id INTEGER FK: res_partner.id Contacto y ficha fiscal en el libro maestro de Odoo.
active BOOLEAN DEFAULT true Estado de habilitación operativa para prestar servicio.
transit_service LÍNEA / CORREDOR
PK: id | FKs: concessionaire_id
Líneas o servicios troncales de transporte (ej. Línea 20, Servicio Troncal Búho). Agrupa los diferentes ramales de ida y vuelta.
Columna Tipo de Dato Restricciones Descripción Funcional
id INTEGER PRIMARY KEY ID único del servicio.
name VARCHAR(255) NOT NULL Nombre del servicio (ej: Línea 20 - Eléctrico Troncal).
code VARCHAR(32) NOT NULL Código corto de visualización (ej: L20, BUHO).
concessionaire_id INTEGER FK: transit_concessionaire.id Empresa concesionaria responsable de la operación.
service_type VARCHAR(32) SELECTION Tipo de flota requerida (electric / standard).
transit_route RAMAL OPERATIVO
PK: id | FKs: service_id, concessionaire_id
Ramal específico con sentido de circulación (Ida o Vuelta). Es el eje donde se miden las frecuencias, avances e intervalos entre unidades.
Columna Tipo de Dato Restricciones Descripción Funcional
id INTEGER PRIMARY KEY ID único del ramal.
service_id INTEGER FK: transit_service.id Servicio o línea a la que pertenece el ramal.
name VARCHAR(255) NOT NULL Nombre del ramal (ej: L20-E1 IDA: Asunción a J.A.S.).
direction VARCHAR(16) SELECTION Sentido del trayecto (outbound / inbound).
length_km FLOAT NOT NULL Longitud total oficial del trayecto en kilómetros.
transit_route_shape POSTGIS TRAZA (LINESTRING)
PK: id | FKs: route_id | PostGIS SRID 4326
Geometría vectorial de alta precisión del recorrido. Soporta versionado bi-temporal (vigencia histórica) para auditar desvíos y obras viales.
Columna Tipo de Dato Restricciones Descripción Funcional
id INTEGER PRIMARY KEY Identificador de versión de la traza.
route_id INTEGER FK: transit_route.id Ramal al que corresponde esta geometría.
geom GEOMETRY(LineString, 4326) POSTGIS GIST INDEX Coordenadas continuas oficiales de la traza de circulación.
valid_from TIMESTAMP NOT NULL Inicio de vigencia de esta versión de trazado.
valid_until TIMESTAMP NULLABLE Fin de vigencia (NULL indica que es la traza activa actualmente).
version INTEGER DEFAULT 1 Número correlativo de versión oficial aprobada por el VMT.
transit_route_checkpoint GEOCERCA PARADA / CABECERA
PK: id | FKs: route_id | PostGIS Point 4326
Puntos de control y geocercas circulares. Discrimina terminales/cabeceras de inicio y fin de vuelta para excluir buses estacionados del tablero lineal.
Columna Tipo de Dato Restricciones Descripción Funcional
id INTEGER PRIMARY KEY ID del checkpoint.
route_id INTEGER FK: transit_route.id Ramal al que pertenece la parada de control.
name VARCHAR(255) NOT NULL Nombre descriptivo (ej: Cabecera Asunción, Control Km 14).
geom GEOMETRY(Point, 4326) POSTGIS POINT Coordenada geográfica central de la geocerca.
radius_meters FLOAT DEFAULT 70.0 Radio circular de detección en metros (cabeceras usan hasta 400m).
is_terminal BOOLEAN DEFAULT false Indica si es terminal/cabecera (excluye al bus del tablero lineal si está dentro).
sequence INTEGER DEFAULT 10 Orden secuencial de paso obligatorio en el itinerario.
transit_dispatch DESPACHO & REGULACIÓN VMT
PK: id | FKs: vehicle_id, driver_id, route_id, service_id
Registro maestro de cada viaje o vuelta ejecutada. Contiene las variables de auditoría de la Res. GVMT 065/2024: semáforo de 5 estados, clasificación por franjas horarias e ICF Provisorio.
Columna Tipo de Dato Restricciones Descripción Funcional
id INTEGER PRIMARY KEY ID del despacho.
vehicle_id INTEGER FK: fleet_vehicle.id Unidad de transporte asignada físicamente a la vuelta.
driver_id INTEGER FK: res_partner.id Chofer profesional habilitado al volante.
route_id INTEGER FK: transit_route.id Ramal recorrido en esta vuelta.
state VARCHAR(32) SELECTION Estado operativo: draft, scheduled, in_transit, completed, cancelled.
semaphore_color VARCHAR(16) COMPUTED Auditoría VMT: green (100%), yellow (tolerancia), red (déficit), purple (desvío), black (no realizado).
franja_horaria VARCHAR(64) COMPUTED Franja oficial: Punta Mañana (05:00-08:30), Valle (08:31-16:00), Punta Tarde (16:01-19:30).
provisorio_icf FLOAT COMPUTED Índice de Cumplimiento de Frecuencia Provisorio según fórmula VMT.
actual_departure TIMESTAMP GPS DETECTED Hora real de salida de la cabecera registrada por geocerca.
actual_arrival TIMESTAMP GPS DETECTED Hora real de llegada a la terminal destino.
fleet_vehicle FLOTA DE BUSES (CORE ODOO)
PK: id | FKs: concessionaire_id, model_id
Ficha técnica de cada autobús. Vincula el odómetro oficial, el identificador único de telemetría del VMT (mean_id) y los sensores de consumo.
Columna Tipo de Dato Restricciones Descripción Funcional
id INTEGER PRIMARY KEY ID interno del vehículo en Odoo.
name VARCHAR(64) NOT NULL Número interno de móvil (ej: BUS-104, COCHE-20).
license_plate VARCHAR(32) UNIQUE Matrícula / Chapa oficial del automotor.
mean_id VARCHAR(64) INDEXED Identificador numérico decimal transmitido por el equipo AVL para validación VMT.
concessionaire_id INTEGER FK: transit_concessionaire.id Empresa operadora titular del ómnibus.
odometer FLOAT TELEMETRY UPDATED Kilometraje acumulado actualizado automáticamente por el broker GPS.
transit_clearing_settlement CLEARING & SUBSIDIOS
PK: id | FKs: period_id, concessionaire_id
Liquidación quincenal/mensual de subsidios al pasaje. Cruza los kilómetros efectivamente comerciales y el ICF auditado con el subsidio reconocido por el Estado.
Columna Tipo de Dato Restricciones Descripción Funcional
id INTEGER PRIMARY KEY ID de la liquidación de clearing.
concessionaire_id INTEGER FK: transit_concessionaire.id Empresa beneficiaria de la compensación de subsidio.
total_commercial_km FLOAT NOT NULL Kilómetros comerciales válidos auditados por pings GPS.
recognized_subsidy NUMERIC(14,2) NOT NULL Monto total en Guaraníes (PYG) liquidado a favor de la concesionaria.
transit_charging_session ELECTROMOVILIDAD
PK: id | FKs: vehicle_id, station_id, charger_id
Control de recarga de autobuses 100% eléctricos. Registra kWh consumidos, estado de salud de batería (SoC) y costos energéticos por kilómetro.
Columna Tipo de Dato Restricciones Descripción Funcional
id INTEGER PRIMARY KEY ID de la sesión de carga.
vehicle_id INTEGER FK: fleet_vehicle.id Bus eléctrico conectado a la electrolinera.
energy_kwh FLOAT NOT NULL Energía suministrada en kilovatios-hora (kWh).
initial_soc FLOAT % Porcentaje de batería inicial al enchufar.
final_soc FLOAT % Porcentaje de batería final al completar la recarga.
